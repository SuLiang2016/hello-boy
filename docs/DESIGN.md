# 成语学习乐园 · 设计文档

> 本文是分期需求确认（grilling）后达成的共识记录：一至四期为 2026-10-25 共识（均已实现），五期、六期为 2026-10-26 共识（未实现，六期只定方向）。所有决定均已由使用者确认。
> 术语定义见根目录 [CONTEXT.md](../CONTEXT.md)，以 CONTEXT.md 为准。

## 一句话

给 7-10 岁孩子的家用学习平台（平板浏览器访问），第一个板块是「成语」：读故事、看总结、看插图、答三道题，攒星星、收徽章、连续打卡。账号内置于本机，数据存本机 SQLite 文件。

## 使用场景

- 服务跑在家里一台 Windows 电脑上（双击 `启动.bat`）。
- 平板（同一 WiFi）浏览器访问 `http://电脑局域网IP:4173`，可「添加到主屏幕」当 App 用。
- 电脑关机则平板打不开——这是已接受的限制。

## 角色与账号

| 角色 | 进入方式 | 能做什么 |
|---|---|---|
| 孩子 | 登录页点自己头像 + 输 4 位口令 | 学成语、看自己的星星/徽章/进度 |
| 家长 | 登录页「家长入口」+ 家长口令（首次向导中设置） | 看每个孩子的进度总览；增改孩子账号、重置口令 |

- 无联网注册。首次打开出现「家长设置向导」：设家长口令 → 创建孩子账号（名字、头像、4 位口令）。
- 登录态长期有效（token 存平板浏览器），点退出才需重新登录。

## 学习流程（一个成语）

1. **学**：插图（SVG 场景画）+ 故事（80-200 字白话，有对话有细节）+ 总结（一两句：什么意思、什么时候用）。
   - 点故事里任意汉字弹出拼音；可开关「全文注音」。
2. **测**：固定三道题——① 选意思（四选一）② 补成语（缺字四选一）③ 用得对吗（情境判断）。
   - 每题即时反馈对错与一句解释。
3. **结果**：3 题对 2 = 学会，得 1 星；全对得 2 星。没通过可立刻重读重测，次数不限。

## 激励

- **星星**：如上。星星只增不减。
- **徽章**：学会 10/30/60 个（成语小书生/成语小达人/成语大王）；连续打卡 3/7/14/30 天（坚持之星/一鼓作气/锲而不舍/恒心传奇）；每学完一个篇章的篇章徽章（共 6 枚，动物大师/数字大师/…）。共 13 枚。
- **打卡**：当天学会至少 1 个新成语即打卡；连续天数中断清零。
- 获得徽章时全屏庆祝动画。

## 进度与数据（SQLite）

- 表：`kids`（名字/头像/口令哈希/设置）、`parents`（家长口令哈希，单行）、`sessions`（token）、`learned`（孩子×成语：星级、次数、学会日期）、`daily`（孩子×日期：新学数、复习数）、`badges`（孩子×徽章×获得时间）。
- 内容数据（成语/故事/题目/插图）是静态 JSON，随前端打包，不入库。
- 复习功能二期（数据结构已按「掌握状态」预留）。

## 插图与视觉

- 每个成语 1 张手绘感几何扁平 SVG（固定调色板，viewBox 400×300，无渐变无文字），画故事的标志性场景。
- 徽章、星星、火焰、头像等图标：同风格自绘 SVG，不依赖外部图标库、不联网。
- 界面：暖米色底、大圆角卡片、大号字（正文 ≥18px）、触摸目标 ≥48px，横竖屏自适应。

## 文案风格（去 AI 味，硬性要求）

- 故事像「家长给孩子讲故事」：口语、有画面、有对话、有具体细节（「宋国有个农夫」优于「古时候有个人」）。
- 禁止：「首先/其次/最后/总而言之」结构；「让我们一起探索…」腔；「我们要/我们应该」说教句；词典腔「形容……」。
- 总结 = 一句孩子能懂的意思 + 一个具体使用场景（「考试没考好，后来认真补功课，这就叫亡羊补牢」）。
- 每条内容过「念出声」测试：读给孩子听不别扭。

## 技术栈

- 前端：Vue 3 + Vite + vue-router + pinia + pinyin-pro（点字出拼音）。
- 后端：Node.js（Express）+ 内置 `node:sqlite`（DatabaseSync），单进程托管 API 与前端构建产物。
- 端口 4173（可在 `server/config.json` 改）。启动时控制台打印局域网访问地址。
- 目录：`成语学习/`（server/ src/ content/ scripts/ 启动.bat），数据文件 `成语学习/data/app.db`。

## 内容生产管线

1. 数据基座：pwxcoo/chinese-xinhua（MIT）核对拼音与出处——典故本身属公有领域，故事全部人工改写，不用任何无 license 语料原文。
2. 6 组内容（每组 10 条）按《内容风格指南》（content/STYLE-GUIDE.md）并行撰写。
3. `scripts/validate-content.js` 校验：JSON 结构、题目答案索引、SVG 根元素与 viewBox、故事字数区间、违禁词扫描（首先/其次/总而言之/让我们一起 等）。

## 二期（2026-10-25 共识，本期范围）

核心目标：**留住孩子**——60 个成语约两个月学完，二期把「学完了」变成「天天想回来」。

### 复习闭环
- 学会后第 **1、3、7、14、30** 天各到期一次；到期成语出现在首页「今日复习」卡。
- 复习形态：每个到期成语**随机抽 1 题**（三种题型随机），答错不惩罚——显示正确答案和解释即算完成该成语的当轮复习。
- 五轮全过 = **牢记**：成语星星金色描边 + 小皇冠角标，「我的星星」页顶部显示「已牢记 N 个」。不新增徽章。
- 到期未复习不惩罚，下一轮间隔从完成日重新起算。
- 激励：完成当天**全部**到期复习 → 打卡 ✓ + 当天最多额外 **+1★**（防刷：每天封顶一次）。任何一次复习也算当天打卡。

### 星星钱包（星星从「累计值」改为「流水账」）
- 新表 `star_events`：learn（学会/升级）/ review（每日复习奖励）/ spend（买装扮）。
- **钱包 = 流水合计**，可花；成语旁的星星仍表示该成语的掌握星（1-2），不随消费减少。
- 一期旧数据迁移：按 learned 表存量补记 learn 事件。

### 装扮间（星星的消费出口）
- 装扮直接戴在**孩子自己的登录头像**上（不引入吉祥物），登录页/首页/我的星星处处可见。
- 首期 10 件，5 个槽位可叠戴：帽子（草帽 5★、虎头帽 8★、魔法帽 10★、博士帽 12★、金皇冠 15★）、眼镜（圆眼镜 5★、墨镜 8★）、围巾（红围巾 5★、彩虹围巾 8★）、头饰（蝴蝶结 6★）。
- 注：原清单中的「小背包」因头像是「脸部特写」没有身体可背，替换为同价位「魔法帽」，总定价不变（约 82★ ≈ 学完全部成语所得的七成）。
- 买了永久拥有、随时换戴、同时候可叠戴多件，星星花掉不退。

### 备份与恢复
- 自动：服务每次启动把 `app.db` 做 WAL 检查点后复制到 `data/backup/`，按日一份，保留最近 7 份。
- 手动：家长中心「备份」下载 JSON 全量导出；「恢复」上传 JSON 原样还原（当前家长会话保留，孩子端需重新登录）。

### 家长端周报
- 家长中心每个孩子卡片：本周新学 X 个、复习 X 次、连续 Y 天（周一为一周起点）。无推送。

### 明确不做（本期）
- 古诗板块（三期）、成语接龙、exe 打包、多设备同步、朗读音频、装扮背景/场景件。

## 三期（2026-10-25 共识，本期范围）

核心目标：**内容扩张**——成语学完不断档，上线第二个板块「古诗」；顺手扩装扮消费出口。

### 古诗板块（主线）

- 内容：**小学必背古诗 75 首**（新课标清单全量），**5 篇章 × 15 首**，篇章按主题分：四季景色、山水田园、送别友情、思乡怀人、咏物言志（具体归属生产时定，主题名可微调）。
- 篇章解锁：学会 **12 首**解锁下一篇章（与成语 8/10 同比例）。
- 古诗卡片四件套：插图（同规范 SVG：18 色调色板、viewBox 400×300、无文字/渐变/滤镜）+ 全诗（点字出拼音、全文注音开关，沿用拼音组件）+ 诗意讲解（白话讲画面）+ 诗人小故事（诗人是谁、在什么情况下写的，像讲成语故事那样讲）。
- 测验三题：① 选诗意（四选一）② 补诗句（缺一个字，四选一）③ 上下句（给上句选下句，四选一）。每题即时反馈 + 一句解释；对 2 题学会、全对 2 星——与成语同规则。
- 复习：接入同一 1/3/7/14/30 天循环，到期随机抽 1 题，答错不惩罚，五轮全过「牢记」戴皇冠；首页「今日复习」卡成语古诗混排；复习奖励星规则不变（当天全部完成 +1★，每天封顶一次）。
- 页面结构完全沿用成语板块骨架（篇章列表 → 卡片学习 → 测验）。

### 激励扩展

- 星星：学会一首 1-2★，进**同一个星星钱包**（钱包不分板块）。总收入约翻倍使现有装扮显得便宜——接受，不改已定价商品，四期用高价件消化。
- 新徽章 8 枚：古诗小书生（学会 10 首）、古诗小达人（30 首）、古诗大王（75 首）+ 篇章徽章 5 枚（命名沿用「XX 大师」模式）。合计 13 + 8 = 21 枚。不做跨板块合成徽章。

### 全局口径

- 今日目标 = 学会 1 个新内容（成语或古诗）；打卡口径不变。
- 家长周报每个孩子卡片加「本周新学古诗 X 首、复习 X 次」。
- 「我的星星」页分板块列进度。
- 首页：古诗岛上线（用掉一座「即将开放」占位，剩一座留给后续板块）。

### 装扮背景件（场景件）

- 形态：**首页「学习乐园」的场景背景画**（星空、草地、海底等），卡片浮于其上；学习页保持暖米色不变（阅读对比度优先）。
- 首期 3-4 件，单价 12-15★，新槽位「场景」一次生效一件、随时换。装扮目录前后端两处（stars.js OUTFITS / 前端 OUTFITS）同步改。

### 数据与工程（生产侧约定）

- 数据基座：chinese-poetry/chinese-poetry（MIT）核对原文；篇目以部编教材通行版为准（异文与多音字读音按教材，如「石径斜」「鬓毛衰」）；拼音 pinyin-pro 生成，多音字人工过一遍。
- 内容管线沿用成语：新内容组撰写 → `validate-content.js` 扩展古诗校验规则（结构/题目答案索引/SVG 规范/禁词）→ `npm run build` 打包。
- 服务端：`learned`/`daily` 等进度表泛化出「板块」维度（迁移需兼容成语存量回填 board=idiom）；复习到期、徽章、周报逻辑按板块泛化。

### 明确不做（本期）

## 四期（2026-10-25 共识，已实现）

> 状态：已实现（2026-10-25）。目标：用成语接龙提高主动打开，但不污染现有的学习、复习、星星和打卡口径。

### 定位与成功标准

- 四期只做成语接龙主线，不做识字板块、exe 打包、多设备同步、跟读音频、专门背诵模式、跨板块徽章。
- 成功 = 孩子行为有变化（主动打开/连续玩）+ 家长能看到接龙数据 + 不破坏现有学习和复习节奏；功能上线本身不算成功。
- 预算 2-3 周做出可玩 MVP；并行跑 1 周真实使用观察（日期/是否主动打开/卡在哪/是否重玩），不阻塞原型；自然使用不足时，MVP 后补一次 3 天陪玩小测。

### 接龙玩法

- 选项式接龙：尾字拼音 → 首字拼音，忽略声调、同音可接；一条链不重复；只用四字、首尾读音稳定的成语；每题 4 个选项，只有 1 个能接上。
- 每日链（所有孩子共用一条，只当天有效，错过不补）+ 自由练习（从链库随机，随时玩）。每日链 6 个成语（5 次接龙），自由练习 6-8 个；无计时、无生命。
- 退出不存档；达到目标步数才算一次「接龙局」。
- 答错：第一次提示正确项首音，可重试；第二次直接标出正确项并继续；每局 3 次提示，每次排除一个错误选项。
- 拼音显示：当前成语高亮最后一个字并标带调拼音，选项高亮第一个字并标带调拼音；提示「声调不同也能接」。
- 完成页：整条接龙链 + 本局新出现的成语；有学习卡片的跳卡片，接龙词库独有的显示一句意思。

### 接龙词库与链库

- 接龙词库 300 个精选成语：59 个四字学习成语作锚点（「千里送鹅毛」五字，按四字规则不进接龙）+ 241 个接龙专属；接龙专属只配一句意思，不建学习卡片，不算学会。
- 数据来源：词条由项目人工筛选常用成语，拼音用 pinyin-pro 生成后人工校正首尾读音（一/不/长/中/数/乐/得/应/调/朝等）；不复制外部词库原文。首尾是多音字的词在 `content/chain/stable-edges.json` 留审核记录（边字 + 读音键），校验脚本会对照；新增词不补记录会被拦下。
- 预生成 90 条人工抽检过的链（链库），长度 6-8；每日链取链首 6 个成语，自由练习取整条链。首批链库全部从四字学习成语起步，验证后再扩充从新词起步的自由链。90 条链已于 2026-10-25 人工抽检（首尾相接、链内不重复、长度、起点、用词适宜）。
- 不做运行时实时拼图：调研显示实时生成约 35% 死胡同、语义接法生硬；90 条链库按日期轮换，自由练习从链库随机。

### 定位与成功标准

- 识字是第三个**板块**，不是练习场：走完整的学会 → 复习 → 牢记流程，进度计入今日目标与打卡，星星进同一个钱包。
- 定位是**补漏提准**，不是启蒙认读——孩子已经能自己读完 80-200 字的成语故事和整首古诗。
- 成功 = 孩子会主动点识字岛 + 家长周报能看到识字数据 + 复习队列没被压垮（首页「今日复习」稳定在 20 条以内）+ **字族卡第二轮复习的正确率高于第一轮**。功能上线本身不算成功。
- 预算 2-3 周做出可用版本，并行跑 1 周真实使用观察（日期/是否主动打开/卡在哪/是否重玩），不阻塞开发。
- **降级顺序写死**：内容生产吃紧时砍装扮（3 件 → 1 件），不砍卡片数量——4 篇 × 25 的篇章结构、篇章徽章数、里程碑阈值全挂在 100 上。
- 年级基准：孩子快三年级（2026-10-26 确认），选字难度与例句用词按三年级取值。

### 内容：字族卡 100 张，4 篇 × 25

| 篇章（术语 / 孩子话） | 内容 |
|---|---|
| 形近字 / 长得像的字 | 己 / 已 / 巳、未 / 末 这类字形相近的辨析组 |
| 多音字 / 一字多音 | 长 cháng / zhǎng 这类一字多音的辨析组 |
| 同音字 / 同音不同字 | 音同而形义不同、靠偏旁和用法分辨的组 |
| 易错字 / 容易写错的字 | 笔画或结构容易认错、写错的字 |

- **篇章名双行显示**：术语作主标题、孩子话作副标题。孩子也需要认识术语，所以不把好名字换掉，而是并列。
- **篇内按难度递进排序**（先松后紧）：每篇前段是一年级水平的常见字，后段升到三年级。孩子先拿到成就感，再逐步加难。
- 学习单位是**字族**：一张卡片 = 一组要放在一起辨析的字。四篇的字互不交叉，100 张卡覆盖 100 组。
- 选字优先级：优先挑孩子在已学的 60 个成语、75 首古诗里遇到过的字，让识字板块与已有内容互相强化，而不是另起一套字表。选字池是这些内容里「成语本身 + 诗题 + 诗句」出现过的 907 个不重复字；对照项（如「巳」「末」）允许是池外新字。
- **选字清单已定稿**：[content/shizi/字族清单.md](../content/shizi/字族清单.md)——100 组字、每组的区分要点、每组锚点出自哪个已学成语或古诗。多音字篇 25 个字已用仓库自带的 pinyin-pro 核验确有多读。
- 篇章解锁沿用通用规则 `ceil(25 × 0.8)` = 学会 20 张开下一篇。
- 字音字义用 chinese-xinhua（MIT）核对，不复制原文；区分口诀、组词、例句全部人工撰写，过「念出声」测试。

### 识字卡片

- **不配插图**——全站第一种没有手绘插图的卡片。视觉主体是字形本身：田字格大字 + 部首与笔画数 + **区分口诀**（一句口语、有画面、不说教的话）。「插图」术语已限定为成语卡片和古诗卡片。
- **部件拆解不做成独立字段或独立组件，并进口诀里说**（「已不封口，已半封口，巳全封口」这类说法本来就带着部件）。理由：口诀已经承担了「怎么分」，再拆一个字段等于同一句话写两遍，还要为此改 100 张卡的结构与校验。决策见 [ADR 0004](adr/0004-shizi-card-shape.md)。
- **一页两张卡，不做两步翻页**：① 字形与区分口诀 ② 「用一用」——每个字配一个词语和一个例句，点字出拼音沿用现有拼音组件，可开关全文注音（识字默认关着：这一张要练的正是认字形）。理由：翻页多一次点击，而这一屏本来就不长；已按此口径过像素验收。同见 [ADR 0004](adr/0004-shizi-card-shape.md)。
- 测验固定三题（四选一，对 2 题学会、全对 2 星，与成语古诗同规则），**题型按篇章分两套**：
  - 形近字 / 同音字 / 易错字篇：① 给词选字（句子挖空）② 选写对的词 ③ 辨字义或辨部件
  - 多音字篇：① 给词选读音 ② 给句选读音 ③ 辨义选词。多音字卡的 `chars` 是**一条一个读音**（同一个字重复出现），学习页只画一格田字格、读音并列在格子下面（`cháng / zhǎng`），组词与例句在「用一用」里各占一行；轻声（地 de、得 de）不带声调是合法的，读音对不对以 pinyin-pro 的多音列表为准。三题的题干格式与校验见 [STYLE-GUIDE 第八节](../content/STYLE-GUIDE.md)。
  - 原本打算「一套题型走天下」（看拼音选字 / 给词选字 / 给词选读音），生产时否掉了：形近字篇 25 组里有 **9 组成员同音**（峰锋蜂全读 fēng、株珠蛛全读 zhū、蜜密 mì、壁璧 bì、磨摩 mó、曈童 tóng、渔鱼 yú、篮蓝 lán、晴情 qíng），「fēng 是哪个字」没有唯一答案；而多音字卡上是**一个字多个读音**，「给词选字」根本无字可选。
- 不做笔顺动画、不做触屏描红、不做书写判定。
