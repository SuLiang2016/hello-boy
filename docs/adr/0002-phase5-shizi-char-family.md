# 五期识字以「字族」为学习单位，不用单字表、不配插图

五期识字的定位是补漏提准，不是启蒙认读——孩子已经能自己读完 80-200 字的成语故事和整首古诗，认读不是瓶颈，瓶颈是形近字（己 / 已 / 巳）和多音字（长 cháng / zhǎng）。因此识字卡片的学习单位定为「字族」：一张卡片教一组要放在一起辨析的字，共 100 张、4 篇 × 25 张（形近字 / 多音字 / 同音字 / 易错字），走完整板块流程（学会、1/3/7/14/30 复习、牢记、篇章解锁、徽章、家长周报）。卡片不配手绘插图，视觉主体是字形本身：田字格大字 + 部件拆解 + 部首与笔画数。

## Considered Options

- 单字卡 × 300（常用字表起步）：孤立单字不符合补漏定位，且按 1-2★/张会再灌 300-600★ 进星星钱包，而现有装扮目录总价只有 216★、成语+古诗学满也只有 270★。
- 词语卡 × 150（读词识字）：漏点仍在单字层面，且与成语板块的内容大量重叠。
- 每卡配一张手绘 SVG：与成语/古诗的视觉语言一致，但 100 张人工量太大，而且场景画对字形辨析是干扰——画一条蛇配「己/已」，孩子记住的是蛇。
- 做笔顺动画或触屏描红：需要引入笔画数据源或手写判定引擎；7-10 岁的书写练习在纸上效率更高，与四期「不做跟读音频」是同一种取舍。

## Consequences

- 字族怎么分组要人工判断，`validate-content.js` 需新增「组内字必须真的形近或同音」「拼音必须带调」等校验规则，比校验一张单字表难。
- CONTEXT.md 的「插图」适用范围被限定为成语卡片和古诗卡片；这是全站第一次出现没有插图的卡片。
- 识字接入三期已泛化好的 board 维度，无需数据迁移；但引入两处新机制：**识字每日新学上限 3 张**（超出当天不计今日目标、不给星）和**每日复习上限 20 条**——三个板块共用一条队列（首页「今日复习」从三期起就是混排的），按「到期最久优先」取题，超出的顺延次日；「当天全部到期 +1★」的判定随之改为「当天上限内的到期全做完」。后者是因为按 3 张/天算，稳态下光识字每天就有 15 条到期，叠加成语古诗会冲到 25-30 条，「当天全部到期」会变成不可能任务，反而毁掉复习动机。
- 选字优先级：优先挑孩子在已学的 60 个成语和 75 首古诗里遇到过的形近字、多音字，让识字板块与已有内容互相强化，而不是另起一套字表。
