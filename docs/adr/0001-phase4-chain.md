# 四期用预生成接龙链做留存，不并入学习进度

四期目标是让孩子每天主动回来，但现有 60 个学习成语按尾音→首音建图最长只能接 3 个、82% 没有出边，因此接龙必须使用独立的接龙词库（约 300 个精选成语，60 个学习成语作锚点 + 约 240 个接龙专属），并预生成 90 条人工抽检过的链，而不是运行时实时拼图。接龙不写 `learned`、不推进复习、不算打卡/今日目标、不给星星，只记录「接龙局」并发 1 枚「接龙高手」徽章；这样游戏带来留存，但不稀释学习、复习和星星的口径。

## Considered Options

- 只用 60 个学习成语接龙：最长链 3，不可玩。
- 运行时按图实时生成：约 35% 会走进死胡同，且容易出现语义生硬的接法。
- 接龙给星星或算打卡：会让孩子用点选项替代学习，破坏现有激励和进度口径。

## Consequences

- 需要生产约 240 条接龙专属成语的一句意思，并人工筛词、抽检 90 条链；这是四期最大的内容成本。
- `chain_plays`、家长周报、备份版本 4、接龙徽章和两件高价装扮是配套工程；它们都不改动 `learned`/`daily`/`review_star` 的学习语义。
- 链库是静态内容，每日链按日期轮换；验证有效后再扩充链库和接龙词库。

## Implementation Note（2026-10-25）

- 「四字」规则过滤掉五字的「千里送鹅毛」，实际学习锚点为 59 个；接龙词库共 300 个（59 锚点 + 241 专属），链库 90 条。
