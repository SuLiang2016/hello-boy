# 六期口算闪卡走「练习场」，不套用板块与复习模型

六期数学大卡定型为口算闪卡：题目由程序自动生成，不预先撰写、不入库成卡片。因为自动生成的题目没有稳定的条目 id，1/3/7/14/30 复习循环没有可挂载的对象，所以口算闪卡不走板块模型，而是和接龙一样归入「练习场」——不写 `learned`、不推进复习、不算打卡和今日目标、不给星星，只记录自己的局数（含用时）并发徽章。计时只做「记录本局用时与历史最佳」，不设倒计时、不扣命。

## Considered Options

- 完整板块（进 `learned`/复习/星星）：复习无对象；要实现必须先发明一个「知识点」实体（如「两位数进位加」）当作复习单位，那是另一个量级的设计。
- 半板块（算打卡与今日目标，不进复习）：会让今日目标出现最省力的路径——孩子可以用几十道口算替代一首古诗，稀释学习口径。
- 倒计时逼答、答错扣命：与全站一贯口径冲突（复习答错不惩罚、接龙答错给提示不给命）。但口算的核心进步刻度是速度，完全不计时又会让「练熟了」无从体现，所以折中为只记用时。

## Consequences

- 六期需要新表（如 `math_plays`，含日期、难度、题数、用时）、自己的段位或徽章、家长周报一行；这些都不改动 `learned`/`daily`/`review_star` 的学习语义，与四期 `chain_plays` 同构。
- 口算闪卡不进星星钱包，因此六期不需要为它新增装扮消费出口。
- 首页板块区在六期上线时改为可滚动两行；四期已确立不加底部 Tab，本次不推翻。
- 如果日后要让数学进入学习口径，前置条件是先定义「知识点」实体——这是本决定唯一的回头路。
