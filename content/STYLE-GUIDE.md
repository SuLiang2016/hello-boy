# 成语内容风格指南（强制执行）

本指南写给内容撰写者。每条内容必须让孩子「念出声听不别扭」，让家长觉得「这是认真写给孩子看的」。

## 一、每条内容的 JSON 结构

```json
{
  "id": "shou-zhu-dai-tu",
  "word": "守株待兔",
  "pinyin": "shǒu zhū dài tù",
  "group": "dongwu",
  "origin": "《韩非子》",
  "story": "……80-200 字白话故事……",
  "summary": "……一两句总结……",
  "illustration": "<svg viewBox=\"0 0 400 300\" xmlns=\"http://www.w3.org/2000/svg\">……</svg>",
  "quiz": [
    { "type": "meaning", "options": ["…","…","…","…"], "answer": 0, "explain": "…" },
    { "type": "fill", "question": "守（　）待兔", "options": ["株","珠","猪","竹"], "answer": 0, "explain": "…" },
    { "type": "usage", "question": "……情境句……", "options": ["用对了","用错了"], "answer": 1, "explain": "…" }
  ]
}
```

字段规则：
- `id`：拼音声调去除后按音节用连字符连接（已给定，不要改）。
- `pinyin`：带声调符号，字与字之间空一格（已给定，不要改）。
- `origin`：古籍名或「古代寓言」之类一句话，≤12 字。
- `quiz` 三题固定顺序：meaning（选意思）→ fill（补成语）→ usage（用得对吗）。
- `meaning` 题无 question 字段；`fill` 的 question 用全角空格「（　）」标出缺字位置；`usage` 的 question 是一句含该成语的情境句，options 固定为「用对了」「用错了」。
- `answer` 是正确选项的下标（0-3）。
- 三题的 `explain` 都是一句孩子能懂的话。

## 二、故事写法（80-200 字）

- 像家长睡前讲故事：口语、有画面、有对话或具体动作。
- 主角要具体：「宋国有个农夫」好过「古时候有个人」。
- 必须讲清故事的因果，结尾一句自然点出成语（「后来大家就用『守株待兔』来说……」这种句子可以有，但不强制、不生硬）。
- 适合 7-10 岁自己阅读：不用的字：生僻文言词、成语套成语。
- 这些典故都是上千年前的公有领域故事，用自己的话重讲，不抄任何词典原文。

**禁止出现**（校验脚本会扫描）：`首先`、`其次`、`总而言之`、`综上所述`、`众所周知`、`由此可见`、`让我们`、`我们应该`、`我们要`、`小朋友们`、`告诉我们`、`形容`、`比喻`(在故事和总结里都别用，explain 里也尽量不用)。

### 故事示范（守株待兔，136 字）

> 宋国有个农夫，一天正在田里锄地，忽听「咚」的一声——一只兔子飞跑过来，一头撞在田边的树桩上，晕死了。农夫白捡一只兔子，晚上美美吃了一顿。他想：种地多累呀，要是天天有兔子撞树桩，我不就天天有肉吃？从此他扔下锄头，天天守在树桩旁边等。兔子再也没来，田里的庄稼却全枯了。

## 三、总结写法（1-2 句，≤60 字）

- 第一句：这个成语是什么意思，用孩子话说。
- 第二句：给一个具体的使用小例子。
- 不写「形容……」，不写「这个故事告诉我们」。

### 示范

> 守株待兔，就是死等天上掉好事，不肯自己干活。考试碰巧蒙对一道题，就再也不复习了——这就是守株待兔。

## 四、测验题写法

- **meaning 选意思**：正确选项用孩子话改写（不是词典释义），3 个干扰项要明显不同义但看起来有点像，不能出现另一个成语的字面误导到歧义。
- **fill 补成语**：挖掉成语中的一个字，4 个选项字形或读音相近（如 株/珠/猪/竹、炼/练），正确项唯一。
- **usage 用得对吗**：写一个孩子生活里的情境句（同学、考试、踢球、吃饭……），一半对一半错交替安排（各组内自己平衡），explain 一句话讲清为什么。

### explain 示范

> 「他天天睡觉等兔子，田都荒了——这就是守株待兔，用对了。」
> 「守株待兔是说傻等不干活，跟跑得快没关系，用错了。」

## 五、插图 SVG 规则

- 根元素固定：`<svg viewBox="0 0 400 300" xmlns="http://www.w3.org/2000/svg">`，不要 width/height。
- 只用这些颜色（调色板固定）：背景 `#FFF7E6`、深墨 `#3D3A36`、红 `#E8604C`、金 `#F5B841`、橙 `#F09A4A`、绿 `#7CA982`、浅绿 `#C8E6A0`、深绿 `#5E8C61`、蓝 `#6FA8DC`、浅蓝 `#BDD9F2`、深蓝 `#4A7FB5`、棕 `#A9744F`、深棕 `#8B5A3C`、肤色 `#F8D8B8`、白 `#FFFFFF`、灰 `#9E9C9A`、粉 `#F5B8B8`、紫 `#A67AB5`。
- 几何扁平风：圆、椭圆、圆角矩形、简单 path；描边用 `#3D3A36` 粗 3px（可选）；**禁止**：渐变、滤镜、`<text>`、外部图片引用、动画。
- 一个成语一张「标志性瞬间」：孩子看图就能猜到是哪个故事（守株待兔 = 树桩 + 飞过来的兔子）。
- 元素 15-40 个，别太空也别太碎；构图主体居中偏下，顶部留天。
- 人物画法从简：圆头 + 梯形身子 + 圆手，不画手指细节；动物用「圆身 + 五官 + 特征部位」。

## 六、交稿要求

- 输出为 JSON 数组，包含指定 10 条，顺序与清单一致，UTF-8 编码。
- 写完必须用 `node -e "JSON.parse(require('fs').readFileSync('文件路径','utf8')); console.log('ok')"` 自检。
- 自己默读一遍每条故事：拗口的地方改到顺。
