# 学习内容风格指南（成语 + 古诗，强制执行）

本指南写给内容撰写者。每条内容必须让孩子「念出声听不别扭」，让家长觉得「这是认真写给孩子看的」。

## 一、每条内容的 JSON 结构

```json
{
  "id": "shou-zhu-dai-tu",
  "word": "守株待兔",
  "pinyin": "shǒu zhū dài tù",
  "group": "dongwu",
  "origin": "《韩非子》",
  "story": "……80-200 字白话故事……",
  "summary": "……一两句总结……",
  "illustration": "<svg viewBox=\"0 0 400 300\" xmlns=\"http://www.w3.org/2000/svg\">……</svg>",
  "quiz": [
    { "type": "meaning", "options": ["…","…","…","…"], "answer": 0, "explain": "…" },
    { "type": "fill", "question": "守（　）待兔", "options": ["株","珠","猪","竹"], "answer": 0, "explain": "…" },
    { "type": "usage", "question": "……情境句……", "options": ["用对了","用错了"], "answer": 1, "explain": "…" }
  ]
}
```

字段规则：
- `id`：拼音声调去除后按音节用连字符连接（已给定，不要改）。
- `pinyin`：带声调符号，字与字之间空一格（已给定，不要改）。
- `origin`：古籍名或「古代寓言」之类一句话，≤12 字。
- `quiz` 三题固定顺序：meaning（选意思）→ fill（补成语）→ usage（用得对吗）。
- `meaning` 题无 question 字段；`fill` 的 question 用全角空格「（　）」标出缺字位置；`usage` 的 question 是一句含该成语的情境句，options 固定为「用对了」「用错了」。
- `answer` 是正确选项的下标（0-3）。
- 三题的 `explain` 都是一句孩子能懂的话。

## 二、故事写法（80-200 字）

- 像家长睡前讲故事：口语、有画面、有对话或具体动作。
- 主角要具体：「宋国有个农夫」好过「古时候有个人」。
- 必须讲清故事的因果，结尾一句自然点出成语（「后来大家就用『守株待兔』来说……」这种句子可以有，但不强制、不生硬）。
- 适合 7-10 岁自己阅读：不用的字：生僻文言词、成语套成语。
- 这些典故都是上千年前的公有领域故事，用自己的话重讲，不抄任何词典原文。

**禁止出现**（校验脚本会扫描）：`首先`、`其次`、`总而言之`、`综上所述`、`众所周知`、`由此可见`、`让我们`、`我们应该`、`我们要`、`小朋友们`、`告诉我们`、`形容`、`比喻`(在故事和总结里都别用，explain 里也尽量不用)。

### 故事示范（守株待兔，136 字）

> 宋国有个农夫，一天正在田里锄地，忽听「咚」的一声——一只兔子飞跑过来，一头撞在田边的树桩上，晕死了。农夫白捡一只兔子，晚上美美吃了一顿。他想：种地多累呀，要是天天有兔子撞树桩，我不就天天有肉吃？从此他扔下锄头，天天守在树桩旁边等。兔子再也没来，田里的庄稼却全枯了。

## 三、总结写法（1-2 句，≤60 字）

- 第一句：这个成语是什么意思，用孩子话说。
- 第二句：给一个具体的使用小例子。
- 不写「形容……」，不写「这个故事告诉我们」。

### 示范

> 守株待兔，就是死等天上掉好事，不肯自己干活。考试碰巧蒙对一道题，就再也不复习了——这就是守株待兔。

## 四、测验题写法

- **meaning 选意思**：正确选项用孩子话改写（不是词典释义），3 个干扰项要明显不同义但看起来有点像，不能出现另一个成语的字面误导到歧义。
- **fill 补成语**：挖掉成语中的一个字，4 个选项字形或读音相近（如 株/珠/猪/竹、炼/练），正确项唯一。
- **usage 用得对吗**：写一个孩子生活里的情境句（同学、考试、踢球、吃饭……），一半对一半错交替安排（各组内自己平衡），explain 一句话讲清为什么。

### explain 示范

> 「他天天睡觉等兔子，田都荒了——这就是守株待兔，用对了。」
> 「守株待兔是说傻等不干活，跟跑得快没关系，用错了。」

## 五、插图 SVG 规则

- 根元素固定：`<svg viewBox="0 0 400 300" xmlns="http://www.w3.org/2000/svg">`，不要 width/height。
- 只用这些颜色（调色板固定）：背景 `#FFF7E6`、深墨 `#3D3A36`、红 `#E8604C`、金 `#F5B841`、橙 `#F09A4A`、绿 `#7CA982`、浅绿 `#C8E6A0`、深绿 `#5E8C61`、蓝 `#6FA8DC`、浅蓝 `#BDD9F2`、深蓝 `#4A7FB5`、棕 `#A9744F`、深棕 `#8B5A3C`、肤色 `#F8D8B8`、白 `#FFFFFF`、灰 `#9E9C9A`、粉 `#F5B8B8`、紫 `#A67AB5`。
- 几何扁平风：圆、椭圆、圆角矩形、简单 path；描边用 `#3D3A36` 粗 3px（可选）；**禁止**：渐变、滤镜、`<text>`、外部图片引用、动画。
- 一个成语一张「标志性瞬间」：孩子看图就能猜到是哪个故事（守株待兔 = 树桩 + 飞过来的兔子）。
- 元素 15-40 个，别太空也别太碎；构图主体居中偏下，顶部留天。
- 人物画法从简：圆头 + 梯形身子 + 圆手，不画手指细节；动物用「圆身 + 五官 + 特征部位」。

- 输出为 JSON 数组，包含指定 10 条，顺序与清单一致，UTF-8 编码。

## 七、古诗（三期）

每篇 15 首，存为 `content/poems/<篇章>.json`。

```json
{
  "id": "jing-ye-si",
  "title": "静夜思",
  "dynasty": "唐",
  "author": "李白",
  "group": "huaren",
  "lines": ["床前明月光，", "疑是地上霜。", "举头望明月，", "低头思故乡。"],
  "fixes": { "为": "wéi" },
  "explanation": "……40-220 字，白话讲画面和意思……",
  "poetStory": "……40-240 字，诗人是谁、在什么情况下写的……",
  "illustration": "<svg viewBox='0 0 400 300' xmlns='http://www.w3.org/2000/svg'>……</svg>",
  "quiz": [
    { "type": "meaning", "question": "《静夜思》写的是什么情景？", "options": ["…", "…", "…", "…"], "answer": 0, "explain": "…" },
    { "type": "fill", "question": "举头望明（　），", "options": ["月", "日", "云", "星"], "answer": 0, "explain": "…" },
    { "type": "next", "question": "举头望明月，", "options": ["低头思故乡。", "疑是地上霜。", "床前明月光，", "…"], "answer": 0, "explain": "…" }
  ]
}
```

- `lines` 3-12 行，每行 2-24 字；保留标点，教材异文按通行版。
- `explanation` 说画面和意思，`poetStory` 讲诗人与写作缘起；都像讲故事，不用词典腔。
- `fixes` 放需要按教材人工确认的多音字（pinyin-pro 可能读错，或不同版本读音有差异），例如 斜 xiá、衰 cuī、见 xiàn、景 yǐng、为 wéi、朝 zhāo、还 huán、缝 féng、华 huā、劲 jìng、笼 lǒng。
- 测验固定 3 题：meaning（选诗意）→ fill（补诗句，正确项是单字，题目严格等于原句把该字换成「（　）」）→ next（给上句选下句，正确项是原诗的下一句）。
- 插图沿用成语的 SVG 规范与调色板：viewBox 400×300，无文字、渐变、滤镜、外链，画这首诗最有辨识度的场景。

## 八、识字（五期）

每篇 25 张，存为 `content/shizi/<篇章>.json`，篇章 key 见 `content/shizi-groups.json`（`xingjin` / `duoyin` / `tongyin` / `yicuo`）。选字清单见 `content/shizi/字族清单.md`。

```json
{
  "id": "zi-feng",
  "group": "xingjin",
  "word": "峰 锋 蜂",
  "pinyin": "fēng fēng fēng",
  "chars": [
    { "zi": "峰", "pinyin": "fēng", "radical": "山", "strokes": 10, "word": "山峰", "sentence": "远处的山峰上飘着白云。" }
  ],
  "tip": "三个字都读 fēng，全靠偏旁认：山字旁是山峰，金字旁是刀锋，虫字旁是蜜蜂。",
  "quiz": [
    { "type": "fill", "question": "远处的山（　）上飘着白云。", "options": ["锋", "峰", "蜂", "风"], "answer": 1, "explain": "山的尖顶是山峰，山字旁。" },
    { "type": "word", "question": "下面哪个词写对了？", "options": ["蜜蜂", "蜜峰", "蜜锋", "密蜂"], "answer": 0, "explain": "蜜蜂是虫子，虫字旁；蜜底下也是虫。" },
    { "type": "meaning", "question": "哪个字说的是「刀最快的那一头」？", "options": ["峰", "蜂", "锋", "风"], "answer": 2, "explain": "金字旁的「锋」，刀刃是金属打的。" }
  ]
}
```

字段规则：

- `id`：`zi-` + 首字拼音（去声调、连字符），如 `zi-ren`、`zi-feng`；首字拼音在篇内撞车时补第二个字，如 `zi-ji-lv`（屐履，避开 `zi-ji` 己已巳）。必须匹配 `/^[a-z-]+$/`，且不能与成语、古诗的 id 重复（`feng` 已被诗《风》占用，所以前缀不能省）。
- `word` / `pinyin`：字族全体成员，字之间空一格。这两个字段是给现有 `titleOf` / `metaOf` 用的，别漏。
- `chars`：字族里每个字一条，顺序与 `word` 一致。`sentence` 和 `word` 里都必须真的出现这个字。
- **没有 `illustration`**——识字卡片不配插图，这是全站唯一一种不带插图的卡片。
- `tip`（区分口诀）：一句话说清这组字怎么分。口语、有画面，不说教。优先用偏旁讲（「山字旁是山峰」），其次用字形讲（「己不封口，已半封口，巳全封口」）。
- `radical` / `strokes`：部首与笔画数，人工填完后用 `npm run audit:glyphs` 机器核对（见本节末「交稿要求」）。

### 多音字篇的字段差异

多音字卡的字族是**一个字的多个读音**（[CONTEXT.md](../CONTEXT.md) 的「字族」本来就含这一形态），所以 `chars` 一条一个读音、同一个字重复出现：

```json
{
  "id": "zi-chang",
  "group": "duoyin",
  "word": "长",
  "pinyin": "cháng zhǎng",
  "chars": [
    { "zi": "长", "pinyin": "cháng", "radical": "长", "strokes": 4, "word": "长短", "sentence": "这根绳子长短正合适。" },
    { "zi": "长", "pinyin": "zhǎng", "radical": "长", "strokes": 4, "word": "长大", "sentence": "我长大要当医生。" }
  ]
}
```

- 顶层 `word` 就是这个字本身（不是「长 长」），`pinyin` 是各读音空格相连。
- 学习页只画**一格**田字格，读音并列写在格子下面（`cháng / zhǎng`），部首与笔画数也只出现一次——同一个字画两格会被当成渲染 bug。两个读音的组词和例句在「用一用」里各占一行，辨析发生在这一屏。
- 同一个字的 `radical` / `strokes` 必须完全一致（抄上一张卡时最容易漏改，校验会拦）。
- 各读音的组词不能重复，也**不能互为子串**，否则第 1 题的题干会同时命中两个读音，答案不唯一。
- **轻声没有声调是合法的**（地 de、得 de），这一篇的拼音不要求带调，改由「必须在 pinyin-pro 的多音列表里」把关。
- 读音超过两个的字只教清单里定的那两个（行、落、空、得、数），其余读音不在卡上出现。

### 例句写法

- 三年级能自己读懂，一句话，有具体画面（「盘子里放了八个苹果」优于「这里有八个人」）。
- **优先用孩子已学过的诗句或成语**：`守株待兔`、`凿壁偷光`、`春眠不觉晓`、`应怜屐齿印苍苔` 这些直接引过来，识字板块就和已有内容互相强化了。引用要写全原句，别改写。
- 生僻字（巳、屐、璧、鳜）不要硬造生活场景，用孩子真认识的固定搭配（巳蛇、木屐、和氏璧）。
- **只能连在一起用的字族（蜻蜓）**：第 1 题被考的那个字，例句里不能出现同族另一个字（挖空会多出第二个正确答案），而「蜻蜓」拆开不成词——所以被考的字只能拿讲字形当例句（「写好『蜓』要记住：右边是『廷』，不是『延』」），别硬造「一只大蜻」这种没有的话。另一个字照常引用诗句。

### 测验三题

四选一，`answer` 是正确项下标（0-3），三题的 `explain` 都是一句孩子能懂的话。**题型按篇章分两套**：

- **形近字 / 同音字 / 易错字篇**：① `fill` 给词选字（句子挖空，用全角「（　）」）② `word` 选写对的词（四个完整词语，只有一个对）③ `meaning` 辨字义或辨部件
- **多音字篇**：① `sound` 给词选读音 ② `sound2` 给句选读音 ③ `meaning` 辨义选词。三题的题干格式是硬约定，校验按格式反查答案：
  - `sound`：`「长大」的「长」读什么？`——题干里必须且只能出现这张卡教过的**一个**组词；正确项就是那个词的读音；同字的另一个读音必须在选项里当干扰项（否则不用辨也能答对）；四个选项都得是拼音。
  - `sound2`：`小树长得很快，这里的「长」读什么？`——必须用 `「字」` 点出考的是哪个字；去掉这个引号后，句子里该字**只能出现一次**（出现多次可能各读各的音）；句子里不能混进另一个读音的组词；另一个读音要在选项里。句子可以直接用卡上的例句，也可以新写，新写的要自己确认读音唯一。
  - `meaning`：`哪个词说的是「生长、变大」？`——正确项必须是卡上教过的组词；四个选项都要含这个字；题干不能把任何选项原样写出来。题干说的意思只能对应一个选项（这条机器查不了，交稿前自己念一遍）。

为什么不用「看拼音选字」：形近字篇 25 组里有 9 组成员同音（峰锋蜂、株珠蛛、蜜密、壁璧、磨摩、曈童、渔鱼、篮蓝、晴情），问「fēng 是哪个字」没有唯一答案。同音字篇整个篇章都是这个情况，一律不出拼音选字题。

选项规则：

- 四个选项必须互不相同（这条最容易写错，交稿前一定跑校验）。
- 干扰项优先用同族的其他字，再补一个族外形近字（人入八 → 加「又」；峰锋蜂 → 加「风」）。
- 一张卡的三题正确答案下标别都落在同一个位置；整篇 25 张的 `answer` 分布要大致均匀（运行时选项会打乱，这条只是为了校验和排查）。

### 禁词

沿用第二节的禁词表，`tip`、`sentence`、`explain` 都会扫。特别注意**「形容」是禁词**——识字卡讲字义时最容易脱口写出「形容……」，改成孩子话（「说的是……」「指的是……」）。

### 交稿要求

- JSON 数组，25 条，顺序与选字清单一致，UTF-8。
- 先 `node -e "JSON.parse(require('fs').readFileSync('文件路径','utf8')); console.log('ok')"` 自检能否解析。
- 再核三件事：每个字的 `pinyin` 用 pinyin-pro 能对上（多音字要确认声明的读音在它的多音列表里）；`sentence` 里引用的诗句/成语确实存在于 `content/poems/` 或 `content/idioms/`；选项无重复。
- 部首与笔画交给机器：`npm run audit:glyphs` 一次核对四篇所有卡片的 strokes / radical / 拼音（cnchar + hanzi-writer-data 双源对笔画，部首取 cnchar 新华口径，拼音以 pinyin-pro 为准），有分歧就非零退出。这三个包不是项目依赖，先 `npm i --no-save cnchar cnchar-radical hanzi-writer-data` 装一次。
- 多音字篇还要看一眼 `npm run validate:content` 打出的「pinyin-pro 整句定音不一致」提示。那不算错（pinyin-pro 对「长得」「慢慢地」这类虚词本来就判不准，所以它不当判分依据），但机器都读错的句子孩子多半也判不准，要么换句子、要么确认句子真没歧义。
- 默读一遍 `tip` 和例句，拗口的改到顺。
